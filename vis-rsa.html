01 Generating the key pair

Two random primes p and q are drawn, multiplied into a modulus N, and used to derive a public exponent e and its private inverse d.

02 Encoding to numbers

Each character becomes an ASCII code, then an 8-bit binary string — the plaintext block RSA will actually operate on.

03 Encrypting each block

Every block m is raised to the power e, modulo N — turning plaintext numbers into ciphertext numbers no one can reverse without d.

04 Decrypting each block

Using the private exponent d, each ciphertext block is raised to the power d, modulo N — recovering the original plaintext number.

05 Decoding & verifying

Recovered numbers are converted back to binary, then back to characters — reassembling the original sentence.
