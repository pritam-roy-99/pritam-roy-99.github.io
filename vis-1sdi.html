1sDI-QKD CJWR Steering Visualizer

A source distributes the entangled state |φ⁺⟩ under depolarizing noise (visibility ν). One photon goes to Alice, whose measurement device is treated as a completely untrusted black box; the other goes to Bob, whose device is trusted and performs fixed Pauli measurements. Each round, both randomly pick a setting i∈{1,2,3}. Rounds where both pick i=3 (σz) generate the raw key; the other matched-setting rounds (i=1 or i=2) are disclosed to estimate the CJWR steering parameter F₃. Security needs only F₃ > 1 — steering from Alice to Bob — certified without trusting Alice's device at all.

Alice (untrusted)  A₁=σx · A₂=−σy · A₃=σz
Bob (trusted)  B₁=σx · B₂=σy · B₃=σz
■ key round: i=j=3
■ CJWR test round: i=j∈{1,2}

Source state: ρν = ν|φ⁺⟩⟨φ⁺| + (1−ν)𝕀/4. On matched settings i=j, |φ⁺⟩ gives perfect agreement between Alice's and Bob's outcomes; depolarizing noise scales the correlator to ⟨Aᵢ⊗Bᵢ⟩ = ν, so QBER = (1−ν)/2. Rounds with i≠j carry no information for either the key or F₃ and are discarded. The steering witness is F₃ = (1/√3)|Σᵢ⟨Aᵢ⊗Bᵢ⟩| ≤ 1 for any local-hidden-state model on Alice's side; a genuine |φ⁺⟩ reaches F₃ = √3. Given the observed pair (Q, F₃), the secret key rate is lower-bounded by the closed-form Devetak–Winter bound r ≥ 1 − h(Q) − h((1+√((F₃²−1)/2))/2).

01 The source emits ρν

Each round, the source produces a two-qubit state ρν = ν|φ⁺⟩⟨φ⁺| + (1−ν)𝕀/4. At ν=1 this is the pure maximally entangled state; as ν drops, depolarizing noise mixes in white noise.

02 One qubit flies to Alice's black box, the other to Bob's trusted device

Watch the pair split and travel to each party.

03 Alice and Bob each pick a random setting and measure

Every round, Alice's black box is fed a random input x∈{1,2,3} and returns a ±1 outcome — its internals are never characterized. Bob independently picks y∈{1,2,3} and applies the corresponding trusted Pauli measurement.

04 Public announcement of settings & classification

Alice and Bob publicly announce only which setting they used each round — never their outcome. Matching settings i=j=3 become key bits (kept secret); matching i=j∈{1,2} become CJWR test rounds (outcomes disclosed); mismatched settings carry no information for either purpose and are discarded.

05 CJWR steering test & key extraction

The three matched-setting correlators combine into the steering parameter F₃ = (1/√3)|E₁+E₂+E₃|. This is the one-sided device-independent security check: Alice's box can be anything at all — security follows purely from whether the observed correlations could come from a local-hidden-state model on her side.
