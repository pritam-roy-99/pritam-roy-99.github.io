DI-QKD Collective-Attack Visualizer

A source distributes entangled pairs; neither Alice's nor Bob's measurement device is trusted — both are treated as black boxes, possibly built by Eve herself. Alice picks between three inputs A₀,A₁,A₂; Bob between two, B₁,B₂. The raw key comes from the (A₀,B₁) rounds; the (A₁,A₂)×(B₁,B₂) rounds are disclosed to compute the CHSH value S. Security follows from S alone — no assumption is made about what's inside either box.

Source state: ρν = ν|Φ⁺⟩⟨Φ⁺| + (1−ν)𝕀/4, measured with B₁=σz, B₂=σx, A₀=σz, A₁=(σz+σx)/√2, A₂=(σz−σx)/√2 — the explicit qubit realization the paper studies for illustration, though the security bound itself assumes nothing about the devices. QBER Q=(1−ν)/2 from the (A₀,B₁) rounds; CHSH value S=2√2ν from the four test combinations, S = ⟨A₁B₁⟩+⟨A₁B₂⟩+⟨A₂B₁⟩−⟨A₂B₂⟩. Eve's Holevo information is bounded by χ(B₁:E) ≤ h((1+√((S/2)²−1))/2) — independent of Q — giving the device-independent Devetak–Winter rate r ≥ 1−h(Q)−χ(B₁:E).

01 The source emits ρν

Each round, the source produces a two-qubit state ρν = ν|Φ⁺⟩⟨Φ⁺| + (1−ν)𝕀/4. Neither box is assumed to know or report what it actually receives.

02 One qubit flies to each black box

Watch the pair split and travel to each party.

03 Alice and Bob each feed their box a random input

Every round, Alice's box gets a random input x∈{A₀,A₁,A₂} and Bob's box gets a random input y∈{B₁,B₂}, chosen freely and kept secret from Eve until the outcomes are already fixed. Each box just returns ±1 — no assumption is made about its internals.

04 Public announcement of inputs & classification

Alice and Bob publicly announce only which input they used each round — never the outcome. (A₀,B₁) rounds become key bits (kept secret); the four (A₁,A₂)×(B₁,B₂) combinations become CHSH test rounds; (A₀,B₂) rounds carry no information for either purpose and are discarded.

05 CHSH test & key extraction

The four test-round correlations combine into the CHSH value S. This is the device-independent security check: it doesn't matter what's inside either box, only whether the observed statistics could be explained by any local hidden-variable model.
