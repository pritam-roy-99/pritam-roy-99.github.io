Open Google Sheet
1

Open Apps Script

In the sheet, select Extensions → Apps Script. A new script editor opens.

2

Copy prepared backend code

Click the button below, then replace the starter code in Apps Script's Code.gs and save.

View source code
3

Authorize your spreadsheet

At the top of Apps Script, choose the function setup and click Run. Review the permission prompt and allow access to the spreadsheet.

Open Execution log. The line labeled PRIVATE SYNC KEY is for your administrator device only. Do not share it in chat or screenshots.

4

Deploy the web app

Click Deploy → New deployment. Choose the gear icon, then Web app. Set Execute as: Me and Who has access: Anyone, then deploy. Copy the generated URL ending in /exec.

This setting allows your public GitHub Pages interface to reach Apps Script. It uses a shared key and is only suitable for a trusted single-administrator setup. Do not share the key or make the spreadsheet publicly editable.

5

Connect and verify

Open your Omelet Service, select Google Sheet Sync, paste the /exec URL and your private sync key. Click Sync pending edits and retrieve records. Add one test entry, sync, and confirm the entry appears on the Orders tab. Cancel the test order and sync so billing stays unchanged.

Go to Omelet Service
Security: Apps Script deployment is an account-level authorization operation. The sync key stays on the device. If multiple administrators or public member ordering are needed, upgrade to role-based access before distribution.
