Google setup and safety

Create a Google Sheet, open Extensions → Apps Script, paste Code.gs from the GitHub folder and run setup(). Record the private key from execution logs, then deploy the script as Web app, Execute as Me, access Anyone. Paste the /exec URL and key here. Google Sheets editing should be limited to the mess administrator. The private key is stored in this browser only. Public Apps Script endpoints using a shared key are not appropriate for member accounts or sensitive data.
